## Project Overview
Shine Mobile Valet is a professional mobile car detailing service operating in Johannesburg and Pretoria. This website provides customers with information about services, pricing, and an online booking system.

---

## Website Pages
| Page | Description |
|------|-------------|
| index.html | Homepage with hero image and service preview |
| about.html | Business background, mission, vision, and team |
| services.html | Full service list with prices |
| enquiry.html | Online booking/enquiry form |
| contact.html | Contact information and service areas |

---

## Features
- Navigation menu on all pages
- Service listings with pricing
- Online enquiry/booking form
- Images showcasing detailing work
- Contact information (phone, WhatsApp, email)
